# Challenge 3 — Create your first Grok Bot

This challenge happens in the Grok Bot app, not in this repo. The screenshot has to show a named bot in the sidebar.

## Bot to create

- **Name:** Campus Desk
- **Job:**

```text
Summarize public campus or Global Hack Week events. Save notes only when asked. Ask before contacting, registering, posting, or submitting.
```

## Steps

1. Open Grok Bot. If signup asks for a card you do not want to enter, stop and ask an organizer.
2. Sign in with the access the event team gave you.
3. Use **+ Create a new Bot**, then **New Bot**.
4. Paste the name and job above into Settings.
5. Screenshot the sidebar with **Campus Desk** visible.

Put the screenshot in this folder as `submission.png` if you want it stored with the repo. Do not commit passwords or session tokens.
