# Challenge 3 — Campus Desk

Do this in the Grok Bot app. It takes under five minutes. This folder does not create the bot.

## Name

Campus Desk

## Job

Paste this into the job field:

```text
Summarize public campus or Global Hack Week events. Save notes only when asked. Ask before contacting, registering, posting, or submitting.
```

## Click path

1. **+ Create a new Bot**
2. **New Bot**
3. **Settings**
4. Set the name to **Campus Desk**
5. Paste the job above

You are done when **Campus Desk** appears in the sidebar.

## What to submit

Submit a screenshot of the sidebar with **Campus Desk** visible.

Challenges are submitted on the [challenge dashboard](https://www.mlh.com/events/global-hack-week-open-source-90/challenges) (`https://ghw.mlh.io/challenges` redirects to the current event).

The screenshot is still required from the Grok Bot app and is not in this repo.
