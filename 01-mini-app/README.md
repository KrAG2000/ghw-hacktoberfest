# Challenge 1 — Campus Week Board

Build a small working app with Cursor. This folder is that app: one page, no build step, no framework.

Open `index.html` in a browser. You can add an event, filter by who it is for, mark it done, switch to dark mode, and reload — the list stays in `localStorage`.

## What Cursor did

Cursor scaffolded the page, split the date rules into `events.mjs` so they can be tested, and wired empty-state, filter, and dark-mode behavior after the first pass only sorted a static list.
