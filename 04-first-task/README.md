# Challenge 4 — Teach Campus Desk one task

Teach **Campus Desk** a public-page skill, then add a routine that only shows you the result.

## Task

Open the Global Hack Week schedule and copy today's listed sessions.

- Page: https://ghw.mlh.com/schedule
- What changes next time: the day, or the word you filter on (for example `workshop`).

## After Teach a Task

Correct the bot if it saved a specific day as if it never changes. Then send:

```text
Run that skill every weekday at 8:00am Asia/Kolkata. Show me the result here. Don't send, post, register, or submit anything.
```

Confirm the routine card. Check that it appears under **Routines**. Pause it after the screenshot if you do not want it to run again during the week.

## Submit

- Screenshot of the skill summary in chat.
- Screenshot of the routine card or the Routines list.
- Two sentences: the skill reads the public schedule and the day or filter word changes each run; the routine is weekday mornings and only reports back in chat.
